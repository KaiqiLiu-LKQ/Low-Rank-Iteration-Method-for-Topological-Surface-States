# Low-Rank-Iteration-Method-for-Topological-Surface-States
Source Code for the paper "Low-Rank Iteration for Efficient Calculations of Topological Surface States"

This repository contains all FEM examples based on the LIM algorithm presented in the paper, as well as all the original data used in the paper.

Authors: 
KaiqiLiu, ChangshenHe, ZihanXie, ShulinSun, LeiZhou, ShaojieMa
